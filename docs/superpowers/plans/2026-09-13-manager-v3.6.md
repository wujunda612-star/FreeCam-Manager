> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release FreeCam Manager V3.6 from the published V3.5 source package, fixing the real WPF menu-separator style path, unifying the four Home summary-card icon metrics, and preserving/verifying the existing single-instance behavior.

**Architecture:** Keep the proven V3.5 updater and package publishing architecture unchanged. Apply a minimal patch to the V3.5 source tree, add regression contracts before production edits, verify RED then GREEN, run Windows WPF publish, and only then publish a deterministic V3.6 Source ZIP through the existing `Publish Manager Update` workflow.

**Tech Stack:** C# 12, .NET 8, WPF/XAML, Python validators, GitHub Actions, deterministic ZIP publishing.

**Spec:** User-approved scope in the 2026-09-13 Manager V3.6 conversation: fix ContextMenu separator full-width rendering; make the four Home summary-card icon presentation consistent; enforce/verify one Manager process with second launch activating the first instance; no unrelated UI redesign and no updater architecture changes.
